# Склейка PDF + PDF → Word (OCR)

Настольная программа на PySide6 под Windows. Две вкладки:

1. **Склейка PDF** — объединяет PDF и текстовые файлы в один PDF.
2. **PDF → Word (OCR)** — конвертирует PDF в `.docx`; страницы-сканы
   распознаются офлайн прямо на компьютере.

## Запуск

Ярлык на рабочем столе открывает окно сразу, без консоли. Вручную:

```powershell
& ".\venv\Scripts\pythonw.exe" ".\pdf_merge_gui.py"
```

С консолью (видно прогресс и ошибки) — то же самое, но `python.exe`.

## Вкладка «Склейка PDF»

- Порядок файлов: кнопки «Вверх/Вниз», перетаскивание внутри списка,
  drag & drop из Проводника.
- `.pdf` подшиваются как есть, без перекодирования.
- `.txt` (и `.md`, `.log`, `.csv`, `.srt`, `.vtt`) верстаются в PDF:
  кириллица через системный шрифт (Arial → Segoe UI → Calibri → Tahoma),
  кодировка определяется автоматически (UTF-8 / CP1251 / UTF-16 / CP866).
- Для расшифровок: таймкод серым, имя спикера жирным
  (`00:23 - 01:07 Екатерина В.: …`).
- Закладки в итоговом PDF по каждому исходному файлу.
- Необязательный `defaults.txt` рядом со скриптом — список путей, которые
  подставляются в список при запуске (по одному на строку).

## Вкладка «PDF → Word (OCR)»

- **Режимы:** авто (текстовый слой, OCR только для сканов) / всегда OCR /
  только текстовый слой.
- **Движки OCR:**
  - **Windows OCR** (`Windows.Media.Ocr`) — встроен в Windows, работает офлайн.
    Языки зависят от установленных языковых пакетов. Основной движок.
  - **Tesseract** — подхватывается из `C:\tools\…` или `Program Files`,
    если установлен.
- Страницы рендерятся в картинки через QtPdf, отдельный бинарь не нужен;
  качество настраивается (по умолчанию 300 dpi).
- Строки распознавания склеиваются в абзацы, переносы по дефису сращиваются,
  таймкоды начинают новый абзац.
- Пакетный режим: несколько PDF за раз, каждый — в свой `.docx`.

## Командная строка

Склейка:

```powershell
& ".\venv\Scripts\python.exe" pdf_merge_gui.py --cli "итог.pdf" "файл1.pdf" "файл2.txt"
```

PDF → Word:

```powershell
& ".\venv\Scripts\python.exe" pdf_merge_gui.py --docx "скан.pdf" --out "C:\Папка" --mode ocr --lang ru
```

## Установка окружения

```powershell
python -m venv .\venv
```

```powershell
& ".\venv\Scripts\python.exe" -m pip install -r requirements.txt
```

Если обычный установщик Python не ставится (например, `msiexec` возвращает 1619
— Windows Installer недоступен, нет прав администратора), подойдёт портативная
сборка CPython с NuGet, распакованная в `python\`. В ней нет `tkinter` — именно
поэтому GUI сделан на PySide6.

## Состав

```
pdf_merge_gui.py   GUI, склейка PDF, вёрстка текста
ocr_docx.py        PDF → Word, движки OCR, рендер страниц
requirements.txt   зависимости
defaults.txt       локальный список файлов (не в репозитории)
python\, venv\     интерпретатор и окружение (не в репозитории)
```

## Антивирус

Avast однажды удалил `.cmd`-лаунчер вместе с папкой программы, приняв его за
угрозу. Поэтому batch-файла нет — ярлык вызывает `pythonw.exe` напрямую. Если
антивирус срабатывает, добавьте папку программы в исключения.
